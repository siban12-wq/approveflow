# AICTE ApproveFlow Datasets and Regulatory References

This directory documents the data sources, regulatory standards, and synthetic datasets utilized by AICTE ApproveFlow.

## 1. Regulatory Framework & Standards
- **Source**: All India Council for Technical Education (AICTE)
- **Document**: Approval Process Handbook (APH) 2024–2027
- **Official URL**: https://www.aicte.gov.in/sites/default/files/APH%20Final.pdf
- **Scope**: Used as an official regulatory benchmark for workflow stages, standard timeline guidelines, prescribed document checklists (e.g. registered land lease deed minimum duration), and human-only authority decision safeguards. It is **not** an application outcome dataset.

## 2. Document & Contract Extraction References
- **CUAD (Contract Understanding Atticus Dataset)**:
  - Repository: https://github.com/TheAtticusProject/cuad
  - Purpose: Benchmarking legal contract clauses, term commencement, and renewal expiration logic.
- **FUNSD (Form Understanding in Noisy Scanned Documents)**:
  - Repository: https://guillaumejaume.github.io/FUNSD/
  - Purpose: Benchmarking visual form key-value pair extraction for institutional certificates.

## 3. Synthetic Application Breach-Risk Dataset
- **File**: `data/synthetic_application_risk.csv`
- **Generated by**: `backend/app/ml/generate_dataset.py`
- **Records**: 15,000 simulated application processing records.
- **Features**:
  - `synthetic_record_id`: Unique identifier (e.g. `SYN-00001`).
  - `application_type`: New, Extension of Approval, Closure, Increase in Intake, New Campus.
  - `workflow_type`: SCRUTINY_EVC_SAC_SHC, SCRUTINY_EVC, ONLY_SCRUTINY, EVC_SAC_SHC, ONLY_EVC.
  - `region`: Northern, Southern, Western, Eastern, South-Western, Central, North-Western, North-Central.
  - `current_stage`: SUBMITTED, SCRUTINY, EVC_QUEUE, SAC_SHC, DECISION_PENDING.
  - `stage_age_working_days`: Elapsed working days in current stage.
  - `stage_sla_working_days`: Configured regulatory SLA target.
  - `deadline_remaining_working_days`: Calculated remaining working days until breach.
  - `prior_stage_delay_count`: Number of delays accumulated in previous processing stages.
  - `institution_resubmission_count`: Clarification/deficiency resubmission iterations.
  - `officer_open_case_count`: Active case load assigned to the processing officer.
  - `officer_overdue_case_count`: Number of overdue cases currently in officer queue.
  - `workload_ratio`: Officer case load relative to regional committee average.
  - `document_completeness_ratio`: Proportion of mandatory supporting documents verified.
  - `clarification_pending`: Binary indicator (1 if deficiency response awaited).
  - `evc_required`: Binary indicator of Expert Visit Committee requirement.
  - `evc_scheduling_delay`: Days taken to constitute and schedule EVC team.
  - `holiday_days_remaining`: Public/gazetted holidays remaining in the SLA window.
  - `historical_stage_delay_rate`: Regional historical stage overrun frequency.
  - `breach_label`: Binary classification target (1 = breached SLA, 0 = on time).
- **Target Leakage Prevention**: No future outcome timestamps, approval decisions, or post-decision events are included in the predictor features. All features reflect state available at prediction time.
- **Limitation Statement**: Performance on synthetic workflow simulations demonstrates algorithmic capability and model calibration, but does not guarantee real-world accuracy without training on verified historical AICTE records. Predictions are advisory only.
